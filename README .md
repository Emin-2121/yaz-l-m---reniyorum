# 🎮 Web Runner & Güçlendirme Oyunu

JavaScript ve HTML5 Canvas kullanılarak geliştirilmiş, dinamik güçlendirme (buff) seçim sistemine ve özel ses efektlerine sahip mini web oyunu.

## 🚀 Özellikler
- **Dinamik Güçlendirme Sistemi:** Koşuya yön veren kart seçim mekaniği
- **Entegre Sesler:** Web Audio API ile gerçek zamanlı üretilen ses efektleri
- **Akıcı Arayüz:** Modern neon temalı görsel kontroller

## 🛠️ Kullanılan Teknolojiler
- HTML5 & CSS3
- Modern JavaScript (ES6+)
- Web Audio API

## 🕹️ Nasıl Oynanır?
1. Projeyi bilgisayarınıza indirin.
2. `oyun.html` dosyasını herhangi bir web tarayıcısında açın.
3. Klavye tuşları (**A / D**) ile karakteri yönlendirin.
